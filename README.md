# Gerard

This repository contains a simple GitHub profile page for Gerard.

## Overview

- Lightweight static homepage
- Custom HTML and CSS only
- Ready for GitHub Pages
- No unused academic template files

## Files

- `index.html` — homepage content
- `style.css` — page styling
- `Gerard_Resume.pdf` — downloadable resume PDF
- `README.md` — project instructions and overview

## Run locally

From the repository root, start a local server:

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000 in your browser.

## Deploy on GitHub Pages

1. Push the repository to GitHub.
2. Open the repository settings.
3. Enable GitHub Pages.
4. Keep the default static site configuration.

This repo is intentionally kept minimal and personal, with only the files relevant to Gerard's profile page.
